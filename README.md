This project is a beginner-friendly full-stack application that demonstrates how to build a REST API using Spring Boot with a MySQL database and connect it to a simple frontend built with HTML, CSS, and JavaScript. It follows a clean layered architecture with separate Controller, Service, and Repository layers. Features include adding, viewing, updating, and deleting student records. Ideal for learning Spring Data JPA, REST endpoints, and frontend-backend integration.

Tech Stack: Spring Boot, Spring Data JPA, MySQL, HTML, CSS, JavaScript
Learning Focus: Layered architecture, CRUD REST APIs, JPA entity mapping
